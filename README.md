# VAGDroid

Диагностика автомобилей VAG (VW / Audi / Seat / Škoda) на Android — клон классической
программы **VAG-COM Release 311.2** для K-line (KKL) адаптеров.

## Возможности

Все основные функции VAG-COM 311:

| Кнопка | Функция |
|--------|---------|
| 01 | Выбор блока управления (адреса 01–7F с русскими названиями) |
| 02 | Чтение / стирание кодов неисправностей с расшифровкой |
| 03 | Тест исполнителей (пошаговый обход тестов) |
| 04 | Базовые установки |
| 07 | Кодирование блока (Soft. coding + WSC) |
| 08 | Измеряемые группы с подписями из label-файлов и преобразованием физических величин |
| 10 | Адаптация (чтение / тест / сохранение каналов) |
| 11 | Логин (SecurityAccess) |
| —  | Автосканирование по списку кузовов из `AutoScan.txt` |
| —  | Журнал диагностики с сохранением в файл |

## Адаптеры

- **USB KKL VAG-COM 409.1** на чипах FTDI (FT232), Qinheng (CH340/CH341),
  Silicon Labs (CP210x), Prolific (PL2303) — через USB-OTG;
- **Bluetooth KKL** с последовательным профилем SPP (HC-05/HC-06 на базе).

> ELM327-адаптеры **не поддерживаются** — это принципиально другой класс устройств
> (OBD-II сканеры), с VAG K-line блоками KW1281 они не работают.

## Протоколы

- **KW1281** (ISO 9141): slow-init 5 бод бит-бэнгом через BREAK, обмен блоками
  с побайтовым квитированием инверсией;
- **KWP2000** (ISO 14230): fast-init (25 мс BREAK + StartCommunication) и
  продолжение после slow-init для блоков с версией KW2027+.

Логика протокола портирована с эталонного открытого инструмента
[kw1281test](https://github.com/gmenounos/kw1281test) (Greg Menounos), включая
таблицу преобразования измеряемых значений (blafusel.de).

## Данные

В приложение встроены оригинальные данные VAG-COM 311.2:

- `assets/labels/` — 536 label-файлов с русскими/английскими подписями групп;
- `assets/autoscan.txt` — таблица кузовов и адресов блоков;
- встроенная база расшифровок DTC (VAG 5-значные + распространённые OBD P-коды).

> Файлы `CodeRUS.DAT`/`CodeEN.DAT` из оригинального дистрибутива зашифрованы
> производителем и не используются — вместо них своя база кодов.

## Сборка

```bash
./gradlew :app:assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`

## Важно

- Требуется Android 5.1+ (API 22), USB-Host для USB-адаптеров.
- Bluetooth-адаптеры должны быть предварительно спарены в настройках телефона.
- Тест исполнителей физически приводит к срабатыванию узлов (вентиляторы, реле,
  форсунки). Кодирование и адаптация — на свой риск: запишите текущие значения.
- Приложение не для дорожного использования.
